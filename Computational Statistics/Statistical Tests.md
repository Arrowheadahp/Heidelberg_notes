To test a hypothesis is true, we find the probability of the opposite of the hypothesis being true. If this probability is highly unlikely $(<\alpha)$, then the hypothesis is True.

example: To test if $x\le0$ (Null Hypothesis), 
we assume Alternate Hypothesis: $x>0$ and then find it's probability.
If $p(x>0)<\alpha$, then the hypothesis is True.
else, the conclusion is that we don't have enough information to disprove the alternate hypothesis.

Types of error: 

| True$\to$ | H0                      | H1                     |
| --------- | ----------------------- | ---------------------- |
| H0        | $1-\alpha$              | $\beta$ (Type 2 Error) |
| H1        | $\alpha$ (Type 1 Error) | $1-\beta$              |
