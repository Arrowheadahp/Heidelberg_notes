As opposed to Image classification which only detects if the image contains something or not, [[Object Recognition]] is of the following types depending on the result.
### [[Object Detection]]
This is to detect objects and localize (put bounding boxes) around each of the boxes in the image.

Using [[Object Detection]], other applications are:
- [[Semantic Segmentation]]  ![[Semantic Segmentation]]
- [[Instance Segmentation]] ![[Instance Segmentation]]

### [[Vision Transformer]]
Current SOTA methods use Vision Transformers.

### [[SWIN]]: Shifted Window transformer
Uses [[Vision Transformer]] in various scales and then merges them
