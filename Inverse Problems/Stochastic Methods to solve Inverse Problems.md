### Fixed point approaches
This is where we use iterative approaches to get the $f$. 
Iterative approach means that the 
$$f_{k+1}=T[f_k]$$
and this moves it towards the $f^*$ which is the fixed point. This is because inverting a large matrix is hard.
(similar to [[Solving Linear System to evaluate policy]])
Some examples are:
1. [[Landweber Method]]
2. [[Richardson Lucy Method]]
