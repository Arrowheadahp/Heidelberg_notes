Classification is a type of discriminant machine learning problem where the predicted values are qualitative like labels.

All regression models can be converted for classification task but there are multiple models for performing only classification like [[SVM]], [[Logistic Regression]]. The output of Classification is generally a vector with the result in [[One-Hot Encoding]]. Which is a vector with all zeros but the class it belongs to.

[[Neural Network]] can also be used for classification where the most used [[Activation Functions]] in the last layer is [[SoftMax Function]] and the most common [[Loss Function]] used is [[Cross Entropy]].
